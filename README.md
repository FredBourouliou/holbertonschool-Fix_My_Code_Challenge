# Holberton School — Fix My Code challenge

Coursework from Holberton School's software engineering program (2024–2026).

Debugging exercises: each file contained a bug to find and fix.

## Tasks (`challenge/`)

- `0-fizzbuzz.py` — FizzBuzz (Python)
- `1-print_square.js` — print a square of `#` characters (Node.js)
- `2-sort.rb` — sort integer arguments in ascending order (Ruby)
- `3-user.py` — user model with a hashed password (Python)
- `4-delete_dnodeint/` — delete a node at a given index in a doubly linked list (C)

## Build (C task)

```sh
cd challenge/4-delete_dnodeint && gcc -Wall -Werror -Wextra -pedantic *.c -o delete_dnodeint
```
